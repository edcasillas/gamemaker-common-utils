# Core

Import `Core` before every other Common Utils module.

Resources:

- `scripts/common_macros/common_macros.yy`

Provides shared macros and helpers used by the rest of the library:

- `OBJECT_NAME`
- `ROOM_NAME`
- `DELTA_TIME_SECONDS`
- `LAYER_DEPTH_MIN`
- `LAYER_DEPTH_MAX`
- `IS_DEV_BUILD`
- `common_utils_set_notification_handler`
